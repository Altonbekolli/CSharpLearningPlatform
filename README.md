# CSharpLearningPlatform

A modern and interactive learning platform designed to teach **C# and .NET development from fundamentals to advanced concepts**.

The goal of this project is to provide a structured learning environment where developers can improve their C# knowledge through lessons, quizzes, practical exercises and progressively more challenging topics.

---

## About the Project

Learning C# often means jumping between documentation, tutorials, videos and isolated exercises.

**CSharpLearningPlatform** aims to bring these concepts together in one structured platform.

Users will be able to progress through different difficulty levels, learn important C# concepts and test their knowledge through interactive exercises and quizzes.

The platform is designed to cover the complete learning path:

```text
Fundamentals
    =
Beginner
    =
Intermediate
    =
Advanced
    =
Expert
    =
Master
```

The project is currently in active development.

---

## Planned Features

The platform is intended to include:

- Structured C# learning paths
- Interactive quizzes
- Practical programming challenges
- Difficulty-based progression

- Achievements

## Technology Stack

The platform is built with a modern .NET and cloud-native technology stack.

- C#
- .NET 10
- ASP.NET Core
- .NET Aspire
- Terraform
- Microsoft Azure
- Git

The technology stack will continue to evolve as the platform grows.

### .NET Aspire

.NET Aspire is used to orchestrate the different components of the application during development and provides a central environment for running and observing distributed application resources.

### Terraform

Terraform is used to define and provision the required Microsoft Azure infrastructure using Infrastructure as Code.

This allows the cloud infrastructure to be versioned alongside the application instead of being configured manually.

## Development Roadmap

The project will be developed incrementally.

**Phase 1 / Foundation**

- Set up .NET Aspire
- Configure project structure
- Introduce Terraform
- Provision initial Azure infrastructure

**Phase 2 / Application Core**

- Create ASP.NET Core API
- Introduce database persistence
- Define learning content structure
- Implement courses and lessons

**Phase 3 / Learning System**

- Quiz system
- Programming challenges
- Difficulty levels
- Progress tracking
- XP and achievements

**Phase 4 / Advanced Platform**

- Authentication and user accounts
- Advanced C# learning paths
- Analytics and statistics
- Cloud deployment
- Production-ready infrastructure

## Commit Convention

This project follows the Conventional Commits specification.

Format:

`<type>: <description>`

### Types

- `feat:` New feature
- `fix:` Bug fix
- `refactor:` Code restructuring without changing functionality
- `docs:` Documentation changes
- `test:` Adding or updating tests
- `chore:` Maintenance, configuration or tooling changes
- `build:` Build system or dependency changes
- `ci:` CI/CD configuration changes

### Examples

`feat: add quiz system`

`fix: correct user progress calculation`

`refactor: simplify course service`

`docs: update project README`

`chore: configure Terraform`

`ci: add deployment workflow`

## Project Status

**Status:** Early Development

The initial .NET Aspire architecture is currently being established. Infrastructure provisioning with Terraform and Microsoft Azure will follow as the next development step.

## Motivation

This project was created with two goals:

1. Build a platform that makes learning C# structured, practical and engaging.
2. Explore modern .NET development, cloud architecture, Infrastructure as Code and DevOps practices through a real-world application.

Rather than treating these technologies as isolated topics, the project combines them within one continuously evolving application.
